# LIMITS

**Learning to Identify Minimal Information Under Token Span**

LIMITS studies query-focused context construction under a strict token budget. The project compares a strong redundancy-aware optimizer with explicit interaction terms against a sequential reinforcement-learning policy that learns to select sufficient evidence from cluttered candidate contexts.

The initial work will cover:

- controlled multi-hop datasets with known minimal evidence sets;
- redundancy-aware optimization with interactions through third order;
- sequential context selection with reinforcement learning;
- evidence quality, answer accuracy, token use, runtime, and computation measurements;
- scaling experiments across dependency depth and candidate-pool size.

The previous prototype remains outside this repository as reference material.
